# PerishLab

广义上，PerishLab 域是 [perishcode](https://github.com/PerishCode) 作为自然人，在探索大量 Agent 协作能力上限的过程中形成的一系列抽象理念和落地产品。

狭义上，PerishLab 域包括 GitHub 上 PerishLab 组织下的全部仓库、由这些仓库产生的下游产物，以及基于这些产物构建的综合解决方案。

## 产品实例

Bagua 是一个持久终端工作区。它把观察终端与取得控制权分开，客户端断开后，程序仍能继续运行。[阅读 Bagua 项目说明](https://github.com/PerishLab/bagua#readme)
