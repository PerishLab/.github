# PerishLab collaboration defaults

This repository carries the organization-wide issue and pull-request surface
for PerishLab. Product repositories inherit these defaults and do not carry
local overrides.

[GOVERNANCE.md](GOVERNANCE.md) defines Issues and pull requests as the sole
durable work ledger and bounds Concord to Issue-anchored local execution.
Read it at work start and before delivery or closure. It also defines source
and release acceptance targets and their session-associated comment closure.
Repository entry points link to that document rather than copying its policy.

This repository is maintained manually. It carries no product workflow,
release declaration, or Plumb configuration.
