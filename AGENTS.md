# Repository entry

Read [GOVERNANCE.md](GOVERNANCE.md) at work start and again before delivery or
Issue closure. It is the canonical PerishLab Issue, pull-request and acceptance
policy; do not reconstruct it from templates or duplicate it here.

This repository is maintained manually and is outside product governance. Do
not add product-local Plumb configuration, release declarations or workflows.
Inherited forms and the pull-request template remain organization defaults.
Organization-governance workflow sources follow GOVERNANCE.md.

When using Concord for Issue delivery, select the explicit `governance-manual`
authority and provide a current manual review. Read
`concord cookbook concord.delivery.review` for the accepted input and recovery.
Concord checks the exact candidate, provider merge and landed tree.
